# Dark Carnival Auto

Автоподбор героя для события Dota 2. Программа читает панель билетов, выбирает
билет по правилу «самый левый минимальный», автоматически подбирает нужного
героя, проходит матч и возвращается на страницу события. Обрабатывает окно
ошибки сервера, приглашения в группу (отклоняет) и выпадение дропа (принимает).

## Требования

- Windows 10 / 11
- Dota 2 в разрешении **1920×1080**, режим экрана **«Без рамки»**
- Python 3

## Установка

1. **Python 3** — скачать с https://www.python.org/downloads/
   и при установке отметить галочку **«Add Python to PATH»**.
2. **Библиотеки** — запустить `install_deps.bat`
   (поставит `mss`, `opencv-python`, `numpy`, `pyautogui`, `pytesseract`).
3. **Tesseract OCR** (нужен для авточтения новых цифр 0 / 4 / 7 / 9):
   - Страница проекта: https://github.com/UB-Mannheim/tesseract/wiki
   - Прямая ссылка на установщик (Windows 64-bit):
     https://digi.bib.uni-mannheim.de/tesseract/tesseract-ocr-w64-setup-5.5.0.20241111.exe
   - Все версии установщика: https://digi.bib.uni-mannheim.de/tesseract/
   - Ставить в папку по умолчанию `C:\Program Files\Tesseract-OCR` — программа сама её найдёт.

## Запуск

1. Открыть Dota 2 и зайти на страницу события (панель билетов видна).
2. Запустить `run_gui.bat`.
3. Нажать зелёную кнопку — пойдёт отсчёт 5 секунд, за это время переключиться на окно Dota.
4. Повторное нажатие — остановка, закрытие окна — выход.

## Обновление

Новые версии выходят в разделе **Releases**. Чтобы обновиться — скачать
архив свежего релиза и заменить файлы у себя (`learned_digits.json` можно
оставить свой — там накопленные цифры).

## Файлы

- `dark_carnival_hero_picker.py` — программа
- `run_gui.bat` — запуск
- `install_deps.bat` — установка библиотек
- `learned_digits.json` — выученные цифры (создаётся и пополняется автоматически)
